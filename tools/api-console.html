axum-secure-starter — API console

Plain fetch calls against the running server. No dependencies, no build step.
The browser enforces CORS, so this page must be served from an origin the server allows. Start a static server in tools/ on port 8080, then run the API with APP_CORS_ALLOWED_ORIGINS=http://127.0.0.1:8080. Opening this file directly with file:// will fail on every request — that block is the server's CORS policy doing its job, not a bug.
